# Changelog

All notable user-visible changes are documented here.

## [0.1.0] - 2026-08-30

### Added

- Strict offline parsing for a documented Mermaid flowchart subset.
- Semantic node, edge, subgraph, and entry-to-exit route comparison.
- Deterministic text, JSON, and Markdown reports.
- CI-oriented `any`, `breaking`, and `never` failure policies with stable exit codes.
- Resource caps, input overwrite protection, terminal-control escaping, examples, and a failure repair playbook.
